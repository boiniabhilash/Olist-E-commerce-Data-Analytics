# Olist E-Commerce Data Analysis Using Python

## Project Overview

This project analyzes Olist e-commerce data using Python to understand sales performance, customer behavior, payment methods, seller performance, customer reviews, and delivery performance.

The project demonstrates how Python can be used to clean, analyze, visualize, and extract meaningful business insights from real-world e-commerce data.

## Tools Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Analysis Performed

### Order Analysis

* Total order analysis
* Order status distribution
* Monthly order trends

### Delivery Analysis

* Average delivery time
* Early, on-time, and late delivery analysis
* Late delivery analysis
* Delivery-time distribution
* Monthly delivery performance

### Sales and Seller Analysis

* Total product sales
* Total freight cost
* Average Order Value
* Monthly sales trends
* Monthly freight trends
* Monthly AOV
* Top sellers by sales
* Top products by sales
* Top sellers by order count

### Customer, Payment and Review Analysis

* Payment method analysis
* Customer orders by state
* Customer review score distribution

## Key Findings

* The dataset contains 99,441 orders, with 96,478 delivered orders.
* Average delivery time for delivered orders was 12.09 days.
* There were 6,534 late deliveries identified in the analysis, with an average delay of 10.62 days.
* Total product sales were approximately 13.59 million.
* Total freight cost was approximately 2.25 million.
* Average Order Value was approximately 160.58.
* Credit card was the most widely used payment method and generated the highest payment value.
* Review scores were concentrated toward the higher ratings, with 5-star reviews being the most common.
